# Memory Contract — канон памяти экосистемы

> Память обязательна. Молчаливого «пропустить» нет нигде: ни в `/ship`,
> ни в `/dream`, ни во `/flush`. Потерянная память = объяснения по кругу.

## Два контура

1. **Проектный** — рядом с кодом, обычный markdown, читают оба SDK
   (opencode и mcode видят одни и те же файлы):
   - `.opencode/memory/decisions.md` — project-memory модель;
   - `docs/decisions.md` (+ `docs/progress.md`, `docs/techdebt.md` — по смыслу) —
     docs-based модель;
   - `04-Memory/session-log/<дата>.md` — vault-модель (внутри волта).
2. **Хаб (волт OKF)** — страховка и межпроектный поиск: `04-Memory/session-log/`
   (секции с тегом `[ship:<проект>]`), `facts.md`, `active-context.md`,
   центральный индекс `tools/mem-index/index.json` (читается первым).

Глобальные конфиги обоих SDK — один каталог
(`~/.config/mcode` → тот же `opencode-global/.config/opencode`), поэтому
глобальные команды/агенты/плагины общие по построению. Зеркалить надо только
проектные `.mcode/`-файлы — текстом на тот же канон.

## Когда пишется

- `/ship` (memory-gate): дистилляция по правилам `/dream` в проектную память
  + строка-указатель в волт. Нет модели — пишем в волт с тегом проекта.
- `/dream`: глубокая дистилляция после обсуждения. Неоднозначность модели —
  спросить пользователя; нет модели — предложить создать файл, без согласия
  не создавать.
- `/flush`: срочный сброс до компакции. Не дублирует `/dream` и наоборот.
- `session-flush` (плагин): только список изменённых файлов и только туда,
  где `04-Memory` уже есть. В чужих проектах ничего не создаёт.

## Как пишется (идемпотентность)

- Сначала прочитать целевое — писать только новое; повторный прогон не дублирует.
- Append-only: существующие записи не перезаписывать.
- Кратко, на русском, в формате соседних записей; дата + тег проекта в журнале.
- Факты отдельно от гипотез; секреты/ключи — никогда.
- Память — отдельным коммитом, не вперемешку с кодом.
- Коммитить только свой lane точечным `git add <пути>` — никогда `git add -A/-u`
  (иначе в коммит едет чужое; см. пакт AndroidOS).
- Нечего фиксировать — ответить «нечего dream/flush» и ничего не писать.

## Старт сессии читает

`active-context.md` → свежий `session-log` → `facts.md` → центральный индекс.
Локальная команда проекта с тем же именем имеет приоритет над глобальной.
