# Профиль пользователя — Макс

> Этот файл читают все агенты dotfiles перед работой.
> Полная версия: `.opencode/memory/user-profile.md`

## Кто такой
- Вайбкодер, системный инженер, минималист
- Русский язык, терминал-нативный стек

## Стек
- zsh + tmux + neovim + Qtile + Alacritty + Rofi + Dunst + btop + ranger + lazygit

## Принципы
- Минимализм, автоматизация, модульность, документированность
- Никаких секретов в репо, строгий режим, атомарные коммиты
- Тёмная тема, консистентность цветов (wal), скорость

## Anti-goals
- Тяжёлые IDE, графические конфигураторы, сложные setup-скрипты, хардкод
