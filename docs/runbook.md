спекам и отчётам: подробности и доказательства — по ссылкам ниже. Канонический

**Метки достоверности:**
- **Проверено пользователем** — Макс подтвердил работу в живом TUI.
- **Настроено** — биндинг есть в конфиге, но конкретный сценарий может быть не
  проверен в живом TUI.
- **Кандидат** — предложение, не применено.

## Быстрая шпаргалка OpenCode TUI

Лидер по умолчанию — `Ctrl+X`. Для лидер-цепочки нажать и отпустить `Ctrl+X`,
затем нажать следующую клавишу.

| Нужно | Клавиша | Статус и оговорка |
|---|---|---|
| Переключить на следующую недавно использованную модель | `F2` | **Проверено пользователем**; работает при русской раскладке |
| Переключить на предыдущую недавно использованную модель | `Shift+F2` | **Проверено пользователем**; работает при русской раскладке |
| Открыть полный список моделей | `Ctrl+X`, затем `M` (`<leader>m`) | Документированный биндинг; при русской раскладке буквенная вторая клавиша не совпадает — использовать латиницу или `F2`/`Shift+F2` для цикла |
| Переключить вариант модели / reasoning effort | `Ctrl+T` | Биндинг из справочника OpenCode V2; работа именно при русской раскладке здесь не проверялась |
| Открыть список вариантов | `Ctrl+X`, затем `V` (`<leader>v`) | Настроено в `~/.config/opencode/cli.json`; буквенная цепочка не надёжна при русской раскладке |
| Перейти к вкладке по номеру | `Ctrl+X`, затем цифра `1…9` | **Проверено пользователем** при русской раскладке |
| Следующая / предыдущая вкладка | `Ctrl+Tab` / `Ctrl+Shift+Tab` | Стандартные биндинги OpenCode V2; текущая раскладка отдельно не проверялась |
| Палитра команд | `Ctrl+P` | Стандартный биндинг OpenCode V2; поведение при русской раскладке отдельно не проверялось |

### Важное правило русской раскладки

Проверено: `Ctrl+X` и цепочка `Ctrl+X` + цифра работают при русской раскладке;
цепочка `Ctrl+X` + буква — нет, движок получает кириллический символ вместо
латинской буквы. Поэтому `F2` и `Shift+F2` — надёжный быстрый способ листать
модели, а буквенные биндинги ниже пока следует считать **латиница-зависимыми**.
Не обобщать это наблюдение на все сочетания `Ctrl+буква`: проверен именно
второй символ лидер-цепочки.

## Черновики и перезапуск

Пользовательские переопределения заданы в `zsh/.zshrc` через
`OPENCODE_CLI_CONFIG_CONTENT`.

| Действие | Сейчас настроено | При русской раскладке |
|---|---|---|
| Очистить поле ввода | `<leader>d` | Не надёжно; лидер + буква |
| Выйти из приложения | `Ctrl+D` или `<leader>q` | `Ctrl+D` отдельно не проверен; лидер + `q` латиница-зависим |
| Положить черновик на полку | `<leader>z` | Не надёжно; лидер + буква |
| Вернуть последний черновик | `<leader>Shift+Z` | Не надёжно; лидер + буква |
| Показать список черновиков | `<leader>f` | Не надёжно; лидер + буква |
| Перезапустить службу OpenCode | `<leader>Shift+R` | Не надёжно; лидер + буква |
| Внешний редактор промпта | `<leader>e` | Стандартный буквенный лидер-биндинг; при ru не считать доступным |

После изменения определений агентов/глобальной конфигурации нужен полный
перезапуск OpenCode TUI/сессии: простое переключение вкладки недостаточно.
Разбор и проверенный способ диагностики — в [отчёте о `Unknown agent`](../.opencode/memory/session-reports/2026-10-13-agent-registry-stale-after-reload.md).

`Ctrl+C` убран из `prompt.clear`, потому что в инциденте 2026-10-12 он
безвозвратно очищал непустой черновик. Но это не означает, что остальные
буквенные биндинги стали раскладка-независимыми. Пока И-39 не применён, длинный
текст безопаснее готовить в файле/Neovim и не полагаться на полку черновиков
при активной русской раскладке.

**И-39 — исследование завершено, изменение не применено.** Кандидатная схема,
сохраняющая прежние латинские биндинги и добавляющая небуквенные альтернативы:

| Действие | Кандидат небуквенного биндинга |
|---|---|
| Положить черновик | `F3` |
| Вернуть последний черновик | `Shift+F3` |
| Показать полку | `F4` |
| Очистить поле (разрушительное действие — намеренная комбинация) | `Ctrl+Shift+F7` |
| Перезапустить службу | `Ctrl+Shift+F6` |

Кандидаты сверены со справочником OpenCode V2 и текущими конфигами: `F2` и
`Shift+F2` заняты переключением моделей; в OpenCode нет документированных
биндингов на предложенные сочетания; Qtile использует только сочетания с
модификатором Super (`Super+F5/F6/F10`); текущая конфигурация tmux не имеет
прямых F-биндингов; в конфиге Alacritty перехвата F-клавиш нет. Это статическая
сверка, не живой тест новых сочетаний. **Не применено и требует отдельного
согласования Макса и проверки в TUI.**

## Как поддерживать ранбук

- После подтверждения хоткея обновлять его статус на «проверено пользователем»;
  после изменения конфига отмечать «настроено», пока нет живой проверки.
- После реализации/приёмки инструмента обновлять строку статуса и ссылку на
  его спеку или отчёт; не переносить гипотезы в список фактов.
- Obsidian-публикация и дальнейшее зеркало запрошены в
  [`handoff куратору Vault`](handoffs/2026-10-13-dotfiles-operator-runbook.md).
