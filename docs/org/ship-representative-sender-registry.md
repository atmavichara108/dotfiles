# Реестр отправителей представителя AllIs Maya

Внешнее лицо Корабля — **@AllIsMaya**. Наружу пишут только профили-носители
из этого реестра. Письмо или сообщение без следа «кто внутри» — нарушение.

## Отправители представителя

| Профиль-носитель | Зона | Что можно писать от Maya | След «кто внутри» |
|---|---|---|---|
| `portal` | Капитанский портал `-1003786610623` | статусы, квитанции, ответы капитану, маршрутизация | сессия AllIs Maya + ref + ts |
| `ssa` | SSA-контур | текущие аутрич-потоки SSA | сессия-источник + ref + ts |
| `dv` | ДВ-Хаб | коммуникации ДВ-Хаб | сессия-источник + ref + ts |
| `serp` | SERPLUX | коммуникации проекта SERPLUX | сессия-источник + ref + ts |
| `trademind:obsidian-servant` | Группа «🧶Препарыночная🪢» `-1003606744594` | ответы и вопросы проекта TradeMind (реплай на конкретное сообщение + цитаты; лимит ≤3 точных вопроса/сутки) | сессия TradeMind + ref + ts; актор `trademind:obsidian-servant` |

## Формат следа «кто внутри»

Сообщение от Maya в портал содержит в конце человекочитаемую строку:

`— AllIs Maya · источник: <сессия/ведомство> · ref: <идентификатор дела>`

В журнале портала и в ship-mail дополнительно фиксируются:
`who_inside`, `via`, `scope`, `ref`, `ts`, `outcome`.

## Запреты

* Без слова владельца: обязательства, публикации, удаления, финансы, сроки,
  квоты, правка агентских профилей.
* Никогда: секреты, токены, полный текст чужих личных сообщений.
* Бот-пульт и любые интерфейсы не голос Корабля; голос Корабля — Maya.
