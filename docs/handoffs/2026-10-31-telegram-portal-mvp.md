# Handoff 2026-10-31 — Telegram хайтек портал, решение капитана

**Инициатор:** владелец
**Получатель:** ЦУ
**Тема:** Принятие архитектуры капитанского портала для @AllIsMaya

## Слово владельца
Владелец принял рекомендации по MVP и хайтек-варианту с рисками:
1. MVP: бот-представитель + Secretary Mode подключение к @AllIsMaya. Входящие от владельца в портал → бот получает update → маршрутизация в ship-mail inbox сессии AllIs Maya → формирование ответа → отправка обратно в портал от имени представителя.
2. Хайтек-вариант: Mini App как интерфейс портала — кнопки, формы, таски, чек-листы. Данные в сессию AllIs Maya, действия фиксируются в журнале отправителей представителя. Эфемерные сообщения для приватных сводок капитану.
3. Существующие потоки SSA и ДВ-хаб остаются прежними, точка входа/выхода через AllIs Maya.

## Канон и границы
* Представитель — единое внешнее лицо Корабля, @AllIsMaya. Писать от имени могут только агенты из реестра отправителей, каждая отправка фиксируется следом «кто внутри».
* Капитанский портал -1003786610623 — канал капитан ↔ ЦУ через представителя. Решение каноном делает только слово владельца basis: quoted.
* Секреты не в репо. Доступ к аккаунту только через официальные механизмы Telegram Business Bots / Secretary Mode. Никаких прямых взломов.
* Обязательства от имени Корабля, финансы, удаления, канонизация лора — только по явному слову владельца.

## Что ждёт от ЦУ
* Подтвердить маршрут интеграции Telegram портала в контур AllIs Maya с ship-mail.
* Перенаправить wake-события портала из чужого координатора в сессию AllIs Maya.
* Координация с ИЦ по подключению Secretary Mode / Business Connection для @AllIsMaya.
* Зафиксировать реестр отправителей и журнал использования представителя Maya.
* При необходимости запрос Ворот owner-gate для доступа/прав к аккаунту.

## Корректировка по Telegram Business Bots / Secretary Mode
* Secretary Mode работает только в подмножестве приватных чатов владельца.
* Для ответов от имени владельца `can_reply` ограничен приватными чатами с активностью за последние 24 часа.
* Для капитанского портала -1003786610623 (группа) требует отдельной стратегии: бот-админ группы, privacy-off участник либо Channel Direct Messages, если это канал с DM.
* Связь с бизнес-аккаунтом через `business_connection_id`, входящие: business_message / edited_business_message / deleted_business_messages.

## Риски принятые владельцем
* Работа с личным аккаунтом только через официальные API Telegram.
* Минимальные права, прозрачность владельцу, журнал действий, никакого переиспользования данных бизнеса за пределами работы бота.
* Фиксация следа отправителя обязательна.
* Представитель не делает обязательств без слова владельца.
* Токен бота — секрет, вне репо, только через Ворота owner-gate.
