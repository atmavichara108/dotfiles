# Канарейка точечного зондирования

Подход: парные канарейки в двух форматах + позитивный/негативный контроль,
исполнение через subagent-инструмент своей живой сессии (не через `opencode
run` — headless-путь сломан, см. баги).

## Рецепт (проверено 2026-10-26)

1. Песочница `/tmp/permtest`, `git init` (нужен OpenCode-проекту как cwd).
2. Два агента с идентичной семантикой в разных форматах:
   - `permission:` (legacy): `edit: deny`, `bash: {"*": allow, "<паттерн>": deny}`;
   - `permissions:` (V2): список `[{action, resource, effect}]`,
     действия `edit`/`shell`, паттерн-resource — строка команды.
3. Прогон: **скопировать файл в катаонлог агентов активной сессии с
   `mode: subagent`** и вызвать `task(agent=<stem>)` — живьём, по одному
   вызову на действие. (Прямой `opencode run --agent` в headless ловит
   ECONNRESET на tool-ходе — route через subagent.)
4. Контроль двух типов на каждый агент:
   - **негатив** — команда, попадающая под deny-паттерн;
   - **позитив** — команда ВНЕ паттерна (проверяет, живы ли allow-правила;
     это и отличает «блок мёртв» от «блок работает»).
5. Evidence — side-effect файлы на диске (`/tmp/permtest/positive-*`),
   не текст отчёта субагента.
6. Убрать канареечные файлы из каталога агентов после прогона (через mv,
   `rm*` под ask-гейтом).

## Матрица результатов (opencode v2.1.4, 2026-10-26)

| Проверка | legacy `permission:` | V2 `permissions:` |
|---|---|---|
| команда вне deny-паттерна | **allow** (positive-legacy создан) | **allow** (positive-v2 создан) |
| команда по deny-паттерну | **deny** (legacy1 запрещён) | **deny** (v2one запрещён) |
| запрещённый инструмент | скрыт из каталога агента | скрыт из каталога агента |

Выводы: оба формата грузятся и исполняются; legacy НЕ мёртв (миграция
флота на V2-формат не обязательна); action-имя в V2 — `shell`; запрет
инструмента убирает тул из каталога агента; внутренняя модель прав —
`permissions:[{action,resource,effect}]`, матчинг findLast, дефолт `ask`.

Открыто: прогон канонических канареек через `opencode run` (как в исходном
запросе владельца) — после фикса транспорта headless в Мастерской.
