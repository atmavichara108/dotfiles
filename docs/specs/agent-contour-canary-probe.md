# Канареечная проба прав агентов (стандарт контура)

Штатная точечная проба изменений агентного контура — вместо дорогих e2e на
каждую правку. Канон метода и матрица результатов — в ОШ
(`docs/methods/canary-permission-probe.md`); этот стандарт — мандат
применения.

## Когда гонять

Перед и после правок: схем агентов (фронтматтер, permission/permissions),
модел-роутера/ротации, гейтов канала, реестра адресов. Правка, меняющая
право или формат контура — не считается проверенной словами; нужна живая
проба или ссылка на свежую.

## Правило пробы

1. **Парные агенты-канарейки**: legacy (`permission:` + `bash:`) и V2
   (`permissions:` + `shell`), копии с `mode: subagent` в каталог агентов
   активной сессии; вызов — через `task(agent=...)`.
2. **Негативный контроль** (команда под deny-паттерном) и **позитивный**
   (вне паттерна): позитив отличает «блок мёртв» (deny всего) от «блок
   работает». Без позитива проба ничего не доказывает.
3. **Evidence = файлы-side-effect на диске, не текст агента.**
4. Канареечные файлы убрать после прогона.
5. Headless `opencode run` для проб не годится (баг транспорта
   bugfix-runtool-transport у Мастерской): route через subagent —
   доказанная эквивалентность семантики прав (единый движок).

## Факты платформы (v2.1.4, проверено ОШ)

- Обе формата прав рабочие; миграция флота на V2 НЕ обязательна.
- Запрещённый инструмент скрыт из каталога агента.
- Внутренняя модель: `permissions:[{action, resource, effect}]`, findLast,
  дефолт — ask.

## Что делает УАС как куратор

- Держит метод в стандартах контура; повторные пробы — по сверке со свежими
  фактами платформы при её апгрейде.
- Новые находки по правам/форматам идут в артефакт ОШ (единый источник) с
  пометкой УАС — не вторая копия метода.
