## Целевое состояние

Почтовый хаб — **первый клиент Отдела Приложений** с репо-домом:
репо-дом = пакет `mail-hub/` + stow-пакет `neomutt/` + скрипты конвейера;
секреты и живые конфиги с паролями — вне репо (инвариант AGENTS.md).

## Шаги (в порядке исполнения)

1. **Stow-пакет `neomutt`** — зеркалировать `~/.neomuttrc` в
   `neomutt/.neomuttrc` через `add-package.sh neomutt ~/.neomuttrc`
   (бэкап оригинала + symlink). Приёмка: `stow -n neomutt` чисто, neomutt
   стартует без ошибок, mailboxes грузятся.
2. **Документ-дом отдела** — этот план + roadmap (шаги 2–6 почтового роадмепа:
   сортировка папок, dunst-нотификации, DNS-проба таймером, архив).
3. **Автосинхронизация приёма** — таймер/крон для `mbsync -a` (предложение
   владельцу текстом; включение — его команда, агент не трогает systemd).
4. **Здоровье канала** — дневная проба MX/SPF/DKIM + smoke-отправка; красное →
   инцидент в сторож.
5. **Архив** — недельный бэкап `~/Mail` в состояние (вне репо) + ротация.
6. **Рубка (позже, по слову владельца)** — почта как прибор Рубки: счётчик
   непрочитанных, лента, ответ через Ворота.

## Приёмка (общая)

- Отправка: smoke через msmtp → `smtpstatus=250` (evidence — msmtp.log).
- Приём: `mbsync -a` rc=0; neomutt открывает INBOX и папки без ошибок.
- Секреты: отсутствуют в репо (guard + глаза).
- Дрейф: `stow -n` чисто по всем затронутым пакетам.
