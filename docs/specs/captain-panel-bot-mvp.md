# Бот-пульт капитана — MVP

Цель: кнопки, команды, задачи и приватные ответы в капитанском портале
`-1003786610623`, без голоса Корабля от имени бота.

**Голос Корабля — Maya. Бот — пульт.**

## 1. Области MVP

1. `/status` — сводка по линиям.
2. `/tasks` — задачи капитана.
3. `/incident` — сообщить о сбое.
4. `/help` — список команд.
5. `/settings` — минимальные настройки уведомлений.

## 2. Inline-кнопки MVP

В сообщении `/status`:

```text
[[ Статус портала ]]   [[ Задачи ]]
[[ Инциденты ]]        [[ Маршрут Maya ]]
```

Callback-data:

```text
portal:status
portal:tasks
portal:incidents
portal:route
```

В `/tasks`:

```text
[[ Открыть задачу ]] [[ Закрыть выбранную ]]
[[ Добавить ]]       [[ Назад ]]
```

Callback-data:

```text
portal:task:open
portal:task:close
portal:task:add
portal:back
```

## 3. Правила интерфейса

* Кнопки бота не отменяют правила: канон — только слово владельца.
* Любая команда от невладельца отклоняется до исполнения.
* Ephemeral-ответ — только владельцу; в общем потоке остаётся факт нажатия,
  если это безопасно, но не личный текст чужого сообщения.
* Бот не пишет обязательств от имени Корабля.
* Бот не пишет «Я решил» или «Корабль обязуется»; только «пульт принял»,
  «передано Maya», «ожидает решения владельца».

## 4. Состояния и переходы

1. `idle` — бот слушает команды.
2. `status` — показана сводка.
3. `task_list` — показан список задач.
4. `task_add` — ждёт текст новой задачи.
5. `incident` — отмечено событие, отправлено Maya.
6. `denied` — попытка команды не от владельца; только журнал и ephemeral отказ
   владельцу при надобности.

Переходы только по кнопкам или командам. Нет свободного исполнения по
сообщениям.

## 5. Журнал и данные

* Журнал `~/.local/state/captain-panel/panel-journal.jsonl`.
* Поля: `ts`, `update_id`, `from`, `chat`, `message_id`, `callback_data`,
  `outcome`, `ref`.
* Запрещено: полный текст сообщений не от владельца, секреты, токены.
* Журнал пишется до реакции. Fail-open: сбой реакции не теряет событие.

## 6. Права и секреты

* Бот — минимальные права.
* Токен — только `~/.config/captain-panel/tg.env`, `600`.
* Значения токена/прав не в git, не в письмах, не в журнале.
* Права выдаются через Ворота owner-gate и валидируются ИС перед live.

**Факт 2026-11-01 16:47:** live подтверждён Maya после повторной сверки прав.
Опасные права сняты: `can_delete_messages`, `can_promote_members`,
`can_restrict_members`. Код бота допускает только `getUpdates`, `sendMessage`,
`answerCallbackQuery`; остальные admin-права не используются. Любое расширение
методов/прав — отдельная согласование.

## 7. Smoke-критерии

1. `dry-run` боевых кнопок без сети.
2. Отправка `/status` с кнопками.
3. Нажатие `portal:status` даёт корректный апдейт.
4. `portal:task:add` пишет задачу и журналирует ref.
5. Попытка невладельца даёт корректный отказ.
6. Журнал не содержит секретов.
7. `grep` по `TG_BOT_TOKEN`, `bot[0-9]+:` не находит значений.

## 8. Условие live

Live только после PASS всех smoke-пунктов и явного подтверждения со стороны
AllIs Maya/LD или ИС. Первая live-отправка — тестовая в портал с пометкой
«бот-пульт, не голос Корабля».

## 9. Локальное распознавание голоса и видео

* Модель: `Systran/faster-whisper-small`, локальный HF-кэш
  `~/.cache/huggingface/hub/...`, размер model.bin — 483546902 байт.
* Исполнение: `~/.local/share/pipx/venvs/faster-whisper/bin/python`, stdlib
  faster_whisper, CPU int8.
* Извлечение аудио: `ffmpeg -vn -ac 1 -ar 16000`.
* Скрипты: `scripts/.local/bin/captain-panel-asr-worker.py`,
  `scripts/.local/bin/captain-panel-asr.py`,
  `scripts/.local/bin/captain-panel-media-fetch.py`.
* Крупные файлы: если Bot API не отдаёт медиа больше `~20 МБ`, пульт
  автоматически использует MTProto-фолбэк через профиль `portal`
  (сессия Maya): скачивает сообщение по `chat_id + message_id`, затем ASR.
* Бот-пульт принимает voice, video, video_note и audio/video document:
  скачивает через Bot API, прогоняет ASR, возвращает текст, журналирует
  outcome `media_transcribed` или `media_asr_failed`.
* Журнал не содержит file_id, путей, тела сообщений и секретов.
* Сеть: только локальный HTTP proxy `http://127.0.0.1:10809`,
  `ALL_PROXY` снимается — иначе huggingface сломается на socksio.
