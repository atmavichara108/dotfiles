# Внешний контур — карта маршрутов

AllIs Maya — единое лицо Корабля наружу. Этот документ фиксирует один контур:
портал, mail-hub и вендорная кафедра.

## 1. Роли

* **AllIs Maya** — голос Корабля, маршрутизатор внешнего контура.
* **Captain portal** — канал капитан ↔ AllIs Maya.
* **Mail-hub** — инфраструктура внешней и внутренней почты, курируется Maya.
* **Кафедра вендоров** — под кураторством Maya; агент-носитель будет
  назначён словом владельца и файлом УАС.
* **ИС/ИЦ** — реализация сервисов и кода. Maya не подменяет техисполнителя.

## 2. Маршруты входа

| Вход | Что происходит | Куда идёт дальше |
|---|---|---|
| Капитанский портал | Капитан пишет в `-1003786610623` | `portal-tg-guard` пишет мету-only и будит сессию `ses_e714b5c4bffeh1ri37WHF8Q7Bx` |
| Ответы из ship-mail | Письмо в inbox Maya | Maya обрабатывает: реплай, перевод ведомству, задача |
| Vendor/external mail | Письмо в `mail-hub` | Maya курирует: сортировать, черновик, перевод нужному ведомству |
| Внешний сигнал не из портала | Не автоматическое действие | Сначала решение Maya, при сомнении — слово владельца |

## 3. Маршруты выхода

| Выход | Что происходит | Кто подписывает |
|---|---|---|
| Ответ капитану | Maya пишет в капитанский портал | AllIs Maya |
| Письмо Кораблю | `ship-mail` по peer-registry | Сессия-источник |
| Внешняя почта | `mail-hub send` / `mail-hub flush` | Maya курирует, отдельное поручение |
| Вендорное сообщение | Только по реестру отправителей и без обязательств без слова владельца | Maya или агент-носитель после апрува |

## 4. Кто идёт через кого

1. **Владелец**
   * Капитанский портал.
   * Слово владельца — единственный источник канона и обязательств.
2. **AllIs Maya**
   * Единая точка маршрутизации внешнего контура.
   * Не принимает решения за ЦУ, ИС или вендорную кафедру.
3. **ИС/ИЦ**
   * Реализация бот-пульта, сервисов, миграций, smoke.
4. **УАС/ЦУ**
   * Канонизация агентов и имён, регистры, согласование мандатов.
5. **Vendor-warden / агент вендорной кафедры**
   * После назначения: операционная работа с вендорами под кураторством Maya.

## 5. Красные линии

* Общение ≠ авторизация.
* Обязательства, публикации, удаления, финансы, квоты — только по слову
  владельца.
* Секреты — только Ворота owner-gate и вне репо.
* В портале, почте и вендорных маршрутах не уходят полные тексты чужих
  личных сообщений в журналы без необходимости.
* Любая внешняя отправка имеет след: кто внутри, откуда, ref, ts.
