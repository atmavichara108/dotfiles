# Итерация 3 — чанкинг-ревизия (секции по заголовкам)

Расшифровка (правило владельца): «чанкинг» — нарезка корпуса на куски для
индексирования; «якорь» — заранее записанный ожидаемый ответ контрольного
запроса (файл#строка); «top-5» — первые пять результатов выдачи;
median/p95 — медиана и 95-й перцентиль полного времени запроса
(embedding+поиск) в миллисекундах; «мягко/строго» — две трактовки зачёта
якорей (см. ниже). Гипотеза итерации 3 (карточка ЦУ l9-iter3-start): мелкие
чанки по заголовкам выводят якорную строку в top-5 при сохранении
различимого пространства. Kill-criterion: <5/7 якорей A в top-5.

не отделяются — «магниты»). Индекс пересобран на том же валидном конверте

## Влияние ревизии на замер при обеих трактовках (п.3 директивы ЦУ)

Замер **не зависит** от трактовки: median/p95 — время запроса, трактовка —
классификация вердикта, они независимы. Влияние самой ревизии чанкинга на
замер — есть и измерено (см. таблицу до/после: p95 64.6 → 29.7).
