# Набор гомеостаза Корабля (Р-031)

## Зачем (слово владельца 2026-10-26, basis: quoted)
«работа должна быть такой слаженной, чтобы я не бегал за всеми... и без того
чтобы они жгли токены и память ковыляя на костылях миллионов инструкций и
заплатка на заплатке». Слаженность = нервная система: логи становятся сигналом,
расхождения — инцидентами, человек — капитан, не почтальон.

## Часть 1. Watcher логов (лог → сигнал)
`tools/homeostasis/log-watch.py` (stdlib-only): хвост `~/.local/share/opencode/log/opencode.log`;
паттерны инцидента: `Failed to drain Session`, `AgentNotFoundError`,
`REFUSE`, `failed` от канала. Находка → инцидент в реестр Мастерской с:
временем, sessionID, причиной из лога (дословно), классом. Тихо терять нельзя:
любой сигнал = запись; повтор класса — ссылка на прежний инцидент, не новая диагностика.

## Часть 2. Session-cop (реестр ↔ реальность)
`tools/homeostasis/session-cop.py` (stdlib-only): по `peer-registry.md`
сверхкаждую строку через API: сессия жива? агент резолвится в её projeto?
каталог совпадает? Расхождение = инцидент класса «сессия не там» с авто-причиной
(факт vs реестр). Timer —по таймеру или по требованию. Реестр перестаёт врать:
правка в реестр — только по факту, с датой и причиной.

## Часть 3. Зов с preflight (будильник почты)
`tools/ship-mail/wake.py` + `wake.timer` (systemd --user): по реестру;
idle-сессии с непрочитанной почтой — зов (`opencode run -s`), но ПЕРЕД зовом:
preflight — сессия жива + агент резолвится + ход не активен. Не прошёл preflight —
инцидент с причиной, не слепой повтор. Лимит: один зов на SID за 900 с; сбоны —
в журнал (меты-only). letter.sh — только ручной релей человека.

## Часть 4. INC-реестр с причинами (дисциплина)
Инцидент = класс + корень (из лога/сверки, не догадка) + фикс + evidence + дата.
Перед диагностикой — поиск по классам: seen-before → ссылка, не новая диагностика.
Корень «похожие адреса», «агент не резолвится», «сессия не там» — классы.

## Приёмка
- Watcher ловит реальный `Failed to drain` → инцидент с причиной за <1 мин.
- Session-cop находит расхождение реестр/реальность → инцидент класса «сессия не там».
- Зов: письмо в ящик idle → сессия прочитала, отработала, ack; preflight-отказ →
  инцидент, не молчание.

## Границы
- Ничего не чинит молча: watcher/cop лишь-raising инциденты; фикс — попроцессу.
- Секретов в журналах нет; только меты + причина из лога.
