# Гомеостаз агентного контура (стандарт, Р-031)

Набор гомеостаза держит контур живым: расхождение между реестром и
реальностью перестаёт быть невидимым. Набор — `docs/specs/homeostasis-kit.md`
(watcher логов → инцидент; session-cop «реестр ↔ реальность»; зов с
preflight; INC-дисциплина «классы + корень»). Этот стандарт — правила его
применения.

## Правила (обязательны для всех ведомств контура)

1. **Лог → сигнал.** Значимое событие (отказ канала, потеря письма, провал
   гейта, ошибка модели) не остаётся в хвосте лога: watcher превращает его в
   инцидент с классом.
2. **Расхождение → инцидент.** Реестр (адресов, манифестов, жизненных циклов)
   против факта на диске/в API — не «поправим при случае», а INC с корнем.
3. **Seen-before → ссылка.** Повтор класса = ссылка на прошлый инцидент;
   новое расследование с нуля — только если корень новый.
4. **Молчаливая потеря запрещена.** Провал пишется в журнал честно
   (`failed`/`dead-letter`/отказ на входе). Событие «ушло и не отвечено»
   обрабатывается как инцидент, а не как погода.
5. **Сессия ↔ реестр.** Привязка проекта к сессии — факт (API-проверяемо).
   Перепривязка — вопрос к ИЦ как к владельцу рантайма; реестр не врёт:
   расхождение = инцидент, не правка «на глаз».
6. **Включение юнитов — шаг владельца.** Таймеры гомеостаза (watch-logs 60с,
   wake-sweep 300с, session-cop 1800с) включаются только по его слову.

## Что делает УАС как куратор

- Держит валидатор реестра адресов и манифестов в прогоне (имя без сущности
  — инцидент класса dvhub-inbound-20261024).
- Собирает срез гомеостаза в реестр инцидентов и докладывает порту отчётов
  (ЦУ) по завершении смыслов, не по каждому событию.
- Молчаливая потеря в каналах — прямой провал роли УАС, не «мелочь».
