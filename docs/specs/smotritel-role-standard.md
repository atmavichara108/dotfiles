# Роль «смотритель проекта» — стандарт

Смотритель — **глаза проекта, не руки и не начальник**. Роль введена словом
владельца 2026-10-24, первый живой носитель — Смотритель ДВ-Хаб
(сессия `ses_ea5bee799ffes5WDriyP61xyB5`, манифест `docs/org/dv-hub-custodian.md`).

## 1.Что роль делает

- **Наблюдение**: следит, что в проекте живо, что сломано, что ждёт владельца;
  докладывает по порту отчётов (ЦУ) по завершении смыслов, не по каждому факту.
- **Онбординг контрибьюторов**: принимает внешних участников по стандарту
  приёма (проверка, лицензия, вердикт independent verifier), не ad hoc.
- **Ретрансляция**: вердикты и статусы между сессиями проекта ходят через
  него по канону адресации (peer-registry, INC-18), с сохранением provenance.
- **Регистрация фактов**: замечания инцидентов, дрейфов, ожиданий фиксируются
  в память проекта; письмо ≠ память, канонизируется извлечённое.

## 2. Что роль НЕ делает (границы — дословно)

- Не пишет код в репозиториях проекта: операция — ИЦ.
- Не создаёт агентов и не правит агентную инфраструктуру: УАС/ИЦ.
- Не трогает секреты, env, DNS, права файлов.
- Не читает тела писем адресатов: только метаданные канала.
- Мандат не самозванный (Р-009): полномочие прослеживается до слова
  владельса или спеки; сосед мандат не изготавливает.

## 3.Как роль рождается (обязательная дисциплина)

1. Слово владельца (мандат) — основание, `basis: quoted`, дословно.
2. Манифест роли: `docs/org/<id>.md`, схема 11+4, mandate-source = слово.
3. **Статус `proposed` до существования файла агента.** Манифест-чертёж
   ожиданием не является именем для доставки: имя без сущности — корень
   инцидента dvhub-inbound-20261024.
4. Файл агента — ИЦ, профиль прав R (наблюдение + ретрансляция; `edit`
   ограничен зоной проекта, `task` deny).
5. Вердикт УАС → статус `active`; колонка «Агент» peer-registry заполняется
   только по факту существования файла (валидатор реестра ловит имя без
   сущности до отправки).
6. Правило хода с рождения: первый шаг хода = inbox (канон Р-028).

## 4.Признаки годности (когда роль можно снимать)

- Доклады доходят портом отчётов без ретрансляции владельцем.
- Контрибьюторы принимаются по стандарту, без ad hoc.
- Инциденты фиксируются в память, а не только в чат.
- Простой: не использован → заморозка (цикл жизни И-21), не удаление.
