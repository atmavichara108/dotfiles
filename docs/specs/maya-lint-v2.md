# Maya-lint v2 — спека (contract)

## Цель

Правило «наружу — нейтральный язык» (граница Майи). Детерминированный
инструмент без LLM в цикле: авто-обслуживание словаря — единственная
LLM-работа, редкая и librarian-овская. Карта: гейт — «один-к-один» с
main-protector (тот же механизм, другой словарь).

## Артефакты (реализованы в этом же домашнем spec-домене)

| Файл | Роль |
|---|---|
| `tools/maya-lint/dictionary.json` | словарь-источник-правды (v1, фразы-only, whitelist) |
| `tools/maya-lint/scan.mjs` | детерминированный сканер: report/--gate, git-история и файлы |

## Протокол (5 гейтов согласованы, все реализованы)

> **Append (librarian-решение 2026-10-07, исполнение sysop):** whitelist
> инкремент на исторические git-log записи (fragment-level, не репо-уровень):
> AndroidOS 3×Pip-Boy, dotfiles 1×Pip-Boy — reason
> «historical commit messages referencing dashboard name». История не
> переписывается (rebase/чистка отклонены как опасные). **Профилактика
> будущего:** commit-msg lint в этих репо — отдельный мандат, не сейчас.
> Схема whitelist расширена опциональным полем `fragments` (точный
> подстрочный матч уровня fragment сообщения коммита); обратная совместимость
> (записи без `fragments` — как раньше). Gate не вшит.


1. Словарь — только фразы и составные термы; одиночные интерпретативные слова
   (maya/майя и прочие «kaiju-подобные») запрещены и исключены из v1 явно.
2. Whitelist per-repo: каждое исключение = запись в словаре с `path` + `phrase`
   + `reason` + `owner` (v1 пустой — инициатив на ноль).
3. Словарь JSON — единственный source-of-truth; правит librarian (и только
   librarian), каждый инкремент — append с provenance (гит-история JSON-файла
   и есть журнал: изменение через diff, без молчащих правок).
4. Гейт-режим включается только после 2-недельного report-прогона с ложными
   срабатываниями < 1% на N коммитов; до этого report-only (exit 0 всегда).
5. Кириллица/латиница — оба ок, phrase-only покрывает; перед любым включением
   гейта — dry-run на исторических коммитах (baseline) — сделан, см. ниже.

## Метрики устойчивости (Sustainability-filter, обязательный чек)

- Ресурсы машины: сканер — разовый bind в цикл-вызовах release; порядок grep.
- Память/контекст: в контекст не попадает; вывод — короткий list hits.
- Токеномика: ноль LLM в рутине; LLM — только в редких инкрементах словаря
  (аппенды, negotiation surveys пира). PASS по трём пунктам.

## Приёмка (acceptance)

- старший: спека+артефакты на месте, smoke смоки (report/несовпадение=PASS ловить phrases only/gate exit 1) — зафиксированы;
- независимая приёмка специалиста по памяти (компаньон): код сканера
  пересчитывается без запуска, словарь v1 консистентен с протоколом 036;
- активация gate-режима — после 2-недельного digest + решения Рудры
  (отдельное поручение, не по этой спеке).

## Границы

- Не трогает: AGENTS.md, hooks, release-пайпы — только новые файлы
  `tools/maya-lint/` и эта спека.
- Report-режим — по умолчанию до (4); любые совпадения в Vault — ожидаемые
  (внутри-диегеза), наружу — только hits по внешним репо/файлам.
