# OMZ не обновляется из-за ссылок в custom (гранит №2)

> Статус: высечено 2026-09-30. Апстрим: ohmyzsh/ohmyzsh issue #10928
> («omz update fails for symlinked custom directory»).
> Шапка-принцип внизу — тоже гранит, по слову Макса.

## Правило одной строкой

Внутри `$ZSH` не должно быть ссылок на папки, которые трогает обновление.
Обновление = `git pull --rebase` + автосохранение локальных правок;
сохранение падает на путях «за ссылкой», и умирает всё обновление целиком.

## Механизм (простой)

1. `omz update` перед подтягиванием прячет локальные правки (autostash).
2. Git не умеет прятать правки, лежащие за ссылкой на папку, и говорит:
   «путь за символической ссылкой» → «не могу сохранить» → «не могу».
3. Обновление прерывается. Проверка при новом терминале находит те же
   252 коммита отставания и предлагает снова. Круг каждые 13 дней.

## Как это выглядело у нас (доказательства)

- `~/.oh-my-zsh/custom/plugins` и `.../custom/themes` — ссылки в репозиторий
  (операция 2026-03-01).
- В дереве висят удалённые примеры (`custom/example.zsh` и др.) — грязь,
  которую обновление каждый раз пытается спрятать и не может.
- Следы: проверка ходит (свежий след сентября), попыток слияния нет,
  отставание 252, приглашение всплывает редко (период 13 дней) — всё сходится.

## Простое решение (только по отдельному ДА, это живой дом)

1. Заменить обе ссылки настоящими папками: скопировать содержимое
   из пакета репозитория (те же 3 плагина + тема), ссылку убрать.
   Убирается только ссылка — цель в репозитории не затрагивается.
2. Вернуть удалённые примеры (`git checkout` в `$ZSH`) — убрать грязь.
3. Запустить обновление, проверить версию и отсутствие приглашения.
4. Откат: вернуть две ссылки обратно — одна команда на каждую.

## Запреты навсегда

- Не уводить живые папки, которые обновляются сами (`custom` у omz,
  кэш менеджеров пакетов), под ссылки в репозиторий. Хочешь версионировать
  содержимое — копируй файлы, а не линкуй папки.
- Не чинить «флажками обновления» то, что ломает ссылка: сначала `readlink`.

---

## Гранит поверх гранита (по слову Макса 2026-09-30)

**Простота — залог эффективности. Усложнения ведут к багам.**
Ссылка вместо папки казалась «умным» решением — и родила вечнозелёную
поломку обновления. Простое (настоящие папки + чистая проверка) работает,
хитрое (ссылки + флаги + костыли) гниёт. При выборе решения брать простое,
сложное — только с записанной причиной.
