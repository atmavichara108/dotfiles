# OpenCode хоткеи — аудит и гайд под тайловое управление

Контекст: OpenCode V2 (v2.0.19) в Alacritty под qtile. Лидер OpenCode по
умолчанию `Ctrl+X` (в тексте — `<L>`). qtile-модификатор — Super (`mod4`).
Модификаторы не пересекаются (Super у WM, Ctrl/Alt у TUI), поэтому глобальных
конфликтов почти нет — детали в разделе «Конфликты».

Клавиши настраиваются в `~/.config/opencode/cli.json` в блоке `keybinds`
(НЕ в `opencode.json`). Отключить бинд — `"none"` или `false`.

---

## 1. Твой профиль управления (из qtile keys.py)

| Приём | Биндинг qtile | Философия |
|-------|---------------|-----------|
| Навигация фокуса | `Super + h/j/k/l` | vim-направления |
| Перенос окна | `Super+Shift + h/j/k/l` | тот же hjkl + Shift |
| Ресайз | `Super+Ctrl + h/j/k/l` | тот же hjkl + Ctrl |
| Воркспейсы | `Super + 1..0` | цифры = прямой прыжок |
| Префикс-меню | `KeyChord Super+p → буква` | лидер → мнемоника |
| Смена layout | `Super + Tab` | Tab = цикл |
| Следующее окно | `Super + space` | space = next |

Вывод: ты живёшь на **hjkl**, **цифрах для прямого прыжка**, **Tab для цикла**
и **лидер→буква для меню**. Гайд ниже выравнивает OpenCode под ту же модель.

## 3. Конфликты с qtile

- **Чистое разделение модификаторов.** qtile сидит на `Super`/`Alt`(`mod1`),
  OpenCode — на `Ctrl`/`Ctrl+X`-лидере. Прямых перехватов нет.
- **`Alt+Tab`** — qtile `mod1+Tab` = toggle последних воркспейсов; в OpenCode
  переключение вкладок висит на `Ctrl+Tab`, не на Alt+Tab. Не конфликтует.
- **`Ctrl+1..9`** — не долетает до TUI: Alacritty по умолчанию не шлёт
  `Ctrl+<цифра>` как escape-последовательность. Поэтому прямой прыжок на
  вкладку делай через `<leader>`+цифра (`Ctrl+X`, затем `1`).
- **`F2`/`Shift+F2`** (цикл моделей) и `Ctrl+T` (цикл вариантов) — свободны в
  qtile, работают.

## 4. Предлагаемая раскладка под твой vim-тайловый стиль

Идея: сохранить лидер `Ctrl+X`, но довесить **hjkl-навигацию по вкладкам** и
**прямой доступ к вариантам/агентам**, повторяя твою qtile-мышечную память.
Diff viewer уже vim — его не трогаем.

Блок для `~/.config/opencode/cli.json`:

```jsonc
{
  "keybinds": {
    // --- вкладки: hjkl как в qtile (Super+h/l), но через Ctrl ---
    "session.tab.previous": ["ctrl+shift+tab", "alt+up", "<leader>h"],
    "session.tab.next":     ["ctrl+tab", "alt+down", "<leader>l"],

    // --- прямой прыжок на вкладку: цифры как воркспейсы qtile ---
    // (Ctrl+1..0 Alacritty не шлёт — остаются только <leader>+цифра)
    "session.tab.select.1": "<leader>1",
    "session.tab.select.2": "<leader>2",
    "session.tab.select.3": "<leader>3",
    "session.tab.select.4": "<leader>4",
    "session.tab.select.5": "<leader>5",

    // --- модели/варианты/агенты: лидер → мнемоника (как Super+p меню) ---
    "variant.cycle": "ctrl+t",      // reasoning effort — цикл (оставляем)
    "variant.list":  "<leader>v",   // reasoning effort — выбор из списка
    "model.list":    "<leader>m",
    "agent.list":    "<leader>a",
    "agent.cycle":   "shift+tab",

    // --- навигация по сообщениям: vim-дух ---
    "session.half.page.up":   ["ctrl+alt+u", "<leader>k"],
    "session.half.page.down": ["ctrl+alt+d", "<leader>j"],

    // --- рабочий цикл ---
    "session.new":     "<leader>n",
    "session.list":    "<leader>l",   // внимание: конфликт с tab.next <leader>l ниже
    "session.compact": "<leader>c",
    "prompt.editor":   "<leader>e"
  }
}
```

Внимание: в примере `<leader>l` стоит и на `session.tab.next`, и дефолтно на
`session.list` — выбери одно. Рекомендация под тайловый стиль:
- `<leader>l` / `<leader>h` → вкладки (вправо/влево, как Super+l/h в qtile);
- список сессий перевесить на `<leader>s`… но `<leader>s` занят статусом.
  Вариант: оставить список сессий на `Ctrl+O` (недавние) и `/sessions`, а
  `<leader>l`/`<leader>h` отдать вкладкам.

### Минимальный безопасный набор (рекомендуется начать с него)

Только добавляет hjkl-вкладки и список вариантов, ничего не ломая:

```jsonc
{
  "keybinds": {
    "session.tab.next":     ["ctrl+tab", "alt+down", "<leader>period"],
    "session.tab.previous": ["ctrl+shift+tab", "alt+up", "<leader>comma"],
    "variant.list": "<leader>v"
  }
}
```

Здесь вкладки листаются `<L>.` / `<L>,` — рифма с qtile `Super+period/comma`
(след./пред. монитор), а `<leader>l`/`<leader>h` остаются за списком сессий и
дефолтами. Выбери тот из двух блоков, что ближе к твоей мышечной памяти.

## 5. Шпаргалка «что нажимать»

| Хочу | Клавиши |
|------|---------|
| Сменить модель | `<L>m` или `/models` |
| Сменить высоту ризонинга (цикл) | `Ctrl+T` |
| Сменить высоту ризонинга (список) | `Ctrl+P` → «variant» (или бинд `<L>v`) |
| Листать вкладки | `Ctrl+Tab` / `Ctrl+Shift+Tab` |
| Прыгнуть на вкладку N | `Ctrl+X`, затем цифра |
| Новая вкладка/сессия | `<L>n` |
| Закрыть вкладку | `<L>w` |
| Сменить агента | `Shift+Tab` (цикл) / `<L>a` (список) |
| Прервать генерацию | `Esc` |
| Shell внутри сессии | `!команда` |
| Приложить файл | `@путь` (с `#20-45` для строк) |
| Внешний редактор промпта | `<L>e` |
| Палитра всех команд | `Ctrl+P` |

## 6. Применение

Этот документ — только аудит/гайд, `cli.json` не изменён. Чтобы применить
раскладку: внести выбранный блок `keybinds` в `~/.config/opencode/cli.json`
(если файл застоужен из dotfiles — править пакет, затем `stow -R`),
перезапустить TUI. Неизвестные ID OpenCode отвергает при старте — сверяться с
reference.
