# owner-gate — Ворота владельца

MCP-сервер (stdio, stdlib-only Python), который даёт владельцу **формы в этом
же вызове** (OpenCode 2.1.4, MCP elicitation): да/нет, выбор варианта, секрет,
DNS-запись. Форма показывается, когда агент вызывает инструмент на заявленном
событии. Без вызова сервер спит и не шумит; вне события форма не возникает
(неизвестный `event` = отказ).

## Что внутри

| Файл | Роль |
|---|---|
| `server.py` | MCP-сервер: рукопожатие, 4 инструмента, elicitation-петля, журнал метаданных |
| `events.json` | реестр событий: форма просыпается только по id из этого файла |
| `selftest.py` | прогон петли без OpenCode: инициализация → форма → ответ → результат |

## Инструменты

- `ask_confirm` — да/нет (апрув опасного apply, обход гейта при /ship).
  `decline`/`cancel` = «владелец не ответил» — **не** согласие.
- `ask_choice` — выбор 2..6 вариантов (канонические развилки: S0-сжатие,
  Bases/Dataview, маршрут ведомства).
- `ask_secret` — значение-секрет от владельца; уходит агенту этим же вызовом;
  в журнал попадает только длина, значение — никогда.
- `ask_dns` — DNS-запись (host/тип/значение), которую вставляет только владелец.

## Правила использования (агентам)

1. Вызывать **только** с `event` из `events.json`; неизвестное событие →
   сервер отвергнет вызов без формы (так задумано).
2. Вопрос — простыми словами, с вариантами и последствиями (S0-А5).
3. Ответ `declined`/`cancelled` ≠ согласие: иди по ветке «не одобрено».
4. Секреты и DNS — только через эти ворота; в репо не писать.
5. Журнал (`~/.local/state/opencode/owner-gate/journal.jsonl`) — метаданные
   для ЦУ; содержание форм/ответов в него не попадает.

## События

| id | Когда просыпается | Форма |
|---|---|---|
| `apply.approve` | system-ops: после preflight, перед apply | да/нет |
| `ship.override` | STOP копа при /ship, осознанный обход | да/нет |
| `canon.choice` | 2+ варианта канона на выбор владельца | выбор |
| `mail-hub.secret` | ключ Resend / пароль IMAP от владельца | секрет |
| `mail-hub.dns` | SPF/DKIM/MX в панели регистратора | DNS |

Новое событие = правка `events.json` (триггер + инструмент + канон-ссылка) в
`task/*`-ветке; событие живёт, пока живёт его триггер.

## Конфигурация

```jsonc
// opencode.jsonc
"mcp": {
  "owner-gate": {
    "type": "local",
    "command": ["python3", "/home/rudra/dotfiles/tools/owner-gate/server.py"],
    "enabled": true
  }
},
"permission": { "owner-gate_*": "allow" }
```
