## Шаблон 1 (выдан 07.11) — «Почта: чтение и закрытие первым шагом хода»

Канонические формы (заменить все верхние варианты на них):

```bash
# чтение первым шагом хода
cd /home/rudra/dotfiles && bash tools/ship-mail/ship-mail.sh inbox ses_<SID>

# закрытие отработанных писем
cd /home/rudra/dotfiles && bash tools/ship-mail/ship-mail.sh ack ses_<SID> all
```

Правила шаблона: путь всегда из `~/dotfiles` (не `~/.local/bin` — зеркало
дрейфует); выборка писем — через `inbox` (не `cat`/glob по файлам); `show` —
только для письма, которое читаем; никаких обвязок `python3 -c`/glob.

## Замер (до/после)

- До: счётчик `token-budget` — 3 записи на всю неделю (разрыв питания счётчика
  зафиксирован как факт программы); журнал cmdlog — 3310 почтовых повторов.
- После: повторный `cmdlog.py top` и `token-budget report` после адаптации —
  доля кластера и число форм должны сократиться; шаблон считается принятым,
  когда в `top` доминирует каноническая форма.

## Границы

- Шаблонизируются только безопасные классы (read-only служебные). Опасные
  (sudo, /etc, пакеты) не шаблонизируются никогда — kill-условие mandates.
- append-only журнал не трогаем; каждая рекомендация выводится из формы
  журнала, источник виден.
