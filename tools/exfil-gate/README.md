# exfil-gate — автописание исходящего гейта (приложение 1, требования СБ; условие ступени 4)

> **Условие СБ (письмо d512be909c28, 07.11.2026):** любая правка
> `describe.py` — строкой СБ ДО включения. Это гейт, а не бюрократия: разбор —
> единственная линия защиты для шаблонов. Мониторинг первых шаблонов — в
> суточной строке СБ; при занижении риска гейт закрывается сразу.

Детерминированный разбор команды → человекочитаемое описание для ask-гейта.
Модель не участвует: в горячем пути только разбор.

## Поля (требования СБ, письмо ЦУ ic-app1-and-stage4)

- **ЧТО** — ресурс: файл, stdin, пайп (и от кого поток), «уход без файла».
- **КУДА** — схема://адрес:порт или user@host, и через какую утилиту.
- **РИСК** — класс + факт: внешний адрес вне списка (exfil-класс) либо
  локальный/разрешённый.
- **ЗАЧЕМ** — дословно из цели (`--goal`), не выводится и не додумывается.
- Формат — до четырёх строк с конкретикой; «передаются данные» некорректно.
- Переменный адрес/ресурс — «в переменной X, значение не резолвилось»:
  молча не резолвим, окружение не раскрываем.
- Секретный путь (`~/.secrets/**`) — блок, один разбор с секрет-сторожем.
- Опасные классы (sudo / rm -rf / systemctl stop / chmod / force-push) —
  никогда: автоописание не выдаётся, команда не идёт в гейт.

## Использование

```bash
python3 tools/exfil-gate/describe.py "<команда>" --goal "<цель дословно>"
python3 tools/exfil-gate/describe.py --template "<шаблон со слотами <FILE>>" \
       --slot FILE=/tmp/report.pdf --slot HOST=100.123.51.13
```

Коды: 0 — описано; 2 — блок; 1 — не разобрано. Список разрешённых адресов для
подстановки слотов: `~/.config/opencode/exfil-allow-hosts.json` (добавление —
по слову владельца/ЦУ; по умолчанию локальные + приёмник копий 100.123.51.13).

## Ступень 4: слоты не обходят риск-гейт

Подстановка слотов идёт тем же разбором, что и полная команда, и строже:
секретный путь в слоте = блок, внешний адрес вне списка = блок, опасная
команда, собранная через слот = блок, неподставленный слот = блок.
Принятие шаблона пишется в журнал (кто/когда/какой):

```bash
python3 tools/ship-mail/cmdlog.py adopt --template <имя> [--by <sid>]
```

Журнал: `~/.local/state/opencode/cmdlog/template-adoptions.jsonl`
(append-only).
