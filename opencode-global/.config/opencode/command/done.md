# Протокол завершения задачи

Когда задача из TASKS.md выполнена, выполни чеклист:

## Чеклист

1. **TASKS.md** — перенеси строку задачи из Active/Planned в Done, укажи дату выполнения.

2. **Описать созданное** — зафиксируй результат в соответствующем месте волта:
   - Новая команда → `01-Reference/commands.md`
   - Новый метод → `02-Methods/<method>.md` + ссылка в `00-INDEX.md`
   - Новый факт → `01-Reference/<раздел>.md` или `04-Memory/facts.md`
   - Изменение в проекте → карточка `03-Projects/<project>.md`

3. **VibeOS** — осмысленно обновить ЕСЛИ задача повлияла на философию/методы/принципы.
   Если нет — явно напиши: «VibeOS: без изменений».

4. **active-context.md** — обнови `04-Memory/active-context.md`: убери выполненное, добавь следующее из Planned.

5. **Заверши через /commit** — закоммить изменения с осмысленным сообщением.

## Отчёт

В конце выведи краткий отчёт по каждому пункту чеклиста:
- [ ] TASKS.md: обновлён / не требовался
- [ ] Описание созданного: <путь> / не требовалось
- [ ] VibeOS: обновлён / без изменений
- [ ] active-context.md: обновлён
- [ ] Коммит: создан / не создан (причина)
