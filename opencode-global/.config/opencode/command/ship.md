# /ship — выкладка task-ветки одним заходом

Запуск команды пользователем = подтверждение всего заявленного scope.
Чужие ветки и чужая грязь — не scope: при их наличии остановиться и доложить.

## 0. Preflight — через копа, не глазами

**Обязательно первым шагом** (кредо: классификацию делает код, не модель):

```bash
.venv/bin/python tools/tree-cop/tree-cop.py ship-check --mine <свой-путь> [--mine <...>]
```

Одна строка JSON: `verdict` GO/STOP, `mine`, `foreign`, `skip_worktree`,
`mode_changes`, `origin_main`, `reasons`.

- **GO** — продолжай, не перепроверяй руками то, что уже сказал коп.
- **STOP** — доложи вердикт и жди решения. Молча чинить запрещено.

Ручные `git status`/`fetch` после копа не нужны (коп сам делает fetch).

## 1. Коммиты по зонам

- Один коммит = один сюжет/зона (гейт zone-mix). Несколько сюжетов — несколько коммитов.
- `MIXED_OK=1` только с причиной в сообщении (пример: гейт дублирует зоны по имени файла).
- Skip-worktree: свои правки в `agent/*.md` сначала `unskip`, после коммита вернуть бит.
- Mode: новым скриптам `update-index --chmod=+x` до коммита; mode-правки — только полным коммитом (pathspec сбрасывает mode в 644).
- Сообщения: `feat/fix/docs/test(chore): ...` + scope-пакет.

## 2. Dream

- Дистиллировать сессию по правилам `/dream` в файл памяти проекта (append-only, без дублей).
- Память — тоже сюжет: отдельный `docs:`-коммит в той же ветке.

## 3. Merge + push + чистка

- `switch main` (дерево должно быть чистым — иначе стоп).
- Если своя грязь мешает переключению — убрать ТОЛЬКО её:
  `.venv/bin/python tools/tree-cop/tree-cop.py stash-foreign --mine <...> -m "tree-cop: <причина>"`,
  и сразу после merge вернуть `... tree-cop.py pop`. Чужое не двигать.
- Merge ветки: FF если чистый, иначе `--no-ff` с сообщением `merge: <смысл> (<ветка>)`.
- `push origin main`. Только свои ветки; `--force` — никогда.
- Удалить task-ветку локально и на remote. Чужие ветки не трогать.
- Финальный `status` + `log`: дерево чистое, `main == origin/main`.

## 4. Отчёт

Что уехало (коммиты), что осталось открытым, что чужое замечено рядом.
