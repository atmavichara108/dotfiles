# /flush — глобальный pre-compaction memory flush

Окно контекста — RAM, не диск. Сохрани значимый контекст текущей сессии на
диск до компакции. Команда глобальная: работает из любого проекта, исполняется
в текущем агенте, без привязки к проектному агенту.

## Контекст
!`git log --oneline -5 2>/dev/null`
!`ls -d .opencode/memory docs/decisions.md docs/progress.md docs/techdebt.md 04-Memory 2>/dev/null`

Если вывод пуст — проверь пути своими read-only инструментами (read/glob).

## Задача

1. Определи project root (git root от cwd; если не git-репозиторий — cwd) и
   модель памяти проекта:
   - `.opencode/memory/decisions.md` — project-memory модель;
   - `docs/decisions.md` (и `docs/progress.md`, `docs/techdebt.md`) —
     docs-based модель;
   - `04-Memory/` — vault-модель: дописывай в `04-Memory/session-log/<дата>.md`
     по конвенции проекта.
   - Неоднозначность (несколько моделей или нет модели) — задай пользователю
     прямой вопрос, не выбирай молча. Если модели памяти нет — предложи
     создать `.opencode/memory/decisions.md`; без согласия ничего не создавай.
2. Прочитай ход сессии: что проектировалось, какие решения (ADR), какие правки
   выполнялись, какие принципы/конвенции зафиксированы. Прочитай целевой файл
   памяти — не дублируй уже записанное.
3. Допиши только новое в целевой файл. Формат — как существующие записи в
   нём. Кратно, на русском.
4. Если значимого в сессии не было — ответь «нечего flush» и ничего не пиши.

## Правила

- Append-only: не перезаписывай существующие записи.
- Не коммить — коммит отдельной командой с явным approval.
- Не пиши код/конфиги — только память/заметки. Это не зона dev-агентов.
- Не фиксируй secrets/credentials.
- В репозитории dotfiles действует локальная `/flush` (agent: planner) — она
  имеет приоритет над этой глобальной.

## Использование

- Запуск: `/flush` из любого проекта (global command:
  `~/.config/opencode/command/flush.md`).
- Изменение вступает в силу после перезапуска OpenCode: config и команды не
  hot-reload, активные сессии продолжают работать с уже загруженным конфигом.
