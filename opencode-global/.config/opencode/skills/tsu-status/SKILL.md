# tsu-status — сверхнавык «Статус» (Р-003 навык 1)

Собери картину из: TASKS.md, active-context, последний session-log, peer-registry, route-log, журналы писем (pending/sent/timeout), route-log. Группировка: (а) работает сейчас; (б) ждёт слова владельца — по одной строке с вопросом; (в) блокеры/инциденты; (г) закрыто с evidence за период. Простой язык, без кода и диффов, один экран. Спорное — вопрос с вариантами, не трактовка. Дайджест допиши в session-log (append-only). Одиночная линия — не пересказывай один файл дважды.
