# Обучение

## Методология
Три режима работы, три типа заметок, один пайплайн.

**Режимы:**
- **Разведка** (30%) — свободный вход, захват интересного → `03_Источники/`
- **Изучение** (50-60%) — целевая работа с одной темой в неделю
- **Переработка** (10-20%) — сборка методички из изученного

**Пайплайн:** Источник → Тема → Практика на участке → Методичка

**Правило:** тема без практики = незавершённая тема.

## Статусы тем
- 🔴 `seed` — обозначена, вопросы есть, источников мало
- 🟠 `growing` — изучается, 3+ источников
- 🟡 `harvest` — понимание сложилось, есть план практики
- 🟢 `manual` — переработана в методичку
- 🔵 `tested` — методичка проверена практикой
