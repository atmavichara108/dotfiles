# Справочник свойств (properties)

Единая база значений для всех шаблонов. Используй только значения из этого файла.

## Общие свойства (есть во всех шаблонах)

### type
Тип заметки.

| Значение | Где используется |
|---|---|
| источник | tpl_источник |
| тема | tpl_тема |
| методичка | tpl_методичка |
| moc | MOC-файлы |
| мета | инструкции, справочники |
| реестр | Реестр_каналов |

### status

**Для источников:**

| Значение | Когда ставить |
|---|---|
| inbox | Только что сохранён, не обработан |
| processed | Просмотрен, идеи извлечены, привязан к теме |
| archived | Всё ценное перенесено в тему, можно не возвращаться |

**Для тем:**

| Значение | Когда ставить | Критерий перехода |
|---|---|---|
| seed | Тема создана, вопрос есть | — |
| growing | Активно изучается | Есть вопрос + 3 источника + начаты ключевые идеи |
| harvest | Понимание сложилось | Могу объяснить своими словами + связь с участком + план практики |
| manual | Методичка написана | Чистовик в 04_Методичка/ |
| tested | Проверено практикой | Фото/схема/наблюдение/проект зафиксирован |

**Для методичек:**

| Значение | Когда ставить |
|---|---|
| draft | Черновик, пишется |
| review | Написана, нужно перечитать свежим взглядом |
| done | Готова к использованию |
| tested | Проверена практикой на участке |
| shared | Передана в комьюнити |

### topics
Список тегов-тем. Тип: массив.

| Значение | Область |
|---|---|
| зоны | Зоны пермакультуры |
| сектора | Секторный анализ |
| чтение-участка | Наблюдение и анализ участка |
| почва | Почвоведение, структура, pH |
| вода | Водный контур, ирригация, дренаж |
| климат | Климат, микроклимат, зоны USDA |
| ветер | Ветрозащита, ветровые коридоры |
| солнце | Инсоляция, тень, ориентация |
| деревья | Плодовые, лесные, уход |
| лесосад | Food forest, поликультура |
| однолетние | Овощи, зелень, сезонные культуры |
| компост | Компостирование, вермикомпост |
| мульча | Мульчирование, покровные культуры |
| обрезка | Обрезка плодовых, формирование |
| паттерны | Паттерны в природе |
| этика | Этика пермакультуры |
| принципы | Принципы дизайна |
| субтропики | Субтропическая пермакультура |
| solarpunk | Соларпанк, зелёные технологии |
| экопоселение | Экодеревни, комьюнити |
| животные | Животные в пермасистеме |
| дизайн-участка | Проектирование, планирование |

Можно комбинировать: `topics: [почва, чтение-участка, мой-участок]`

### created / updated
Формат: `YYYY-MM-DD` (например `2026-03-10`).
Заполняй вручную или через Templater.

## Свойства шаблона "Источник"

### format

| Значение | Что это |
|---|---|
| youtube | Видео с YouTube |
| article | Статья, веб-страница |
| book | Книга или глава книги |
| telegram | Пост из Telegram |
| podcast | Подкаст |
| pdf | PDF-документ |

### title
Название материала. Тип: текст. Пример: `"Permaculture Zones Explained"`

### url
Ссылка на материал. Тип: текст. Пример: `"https://youtube.com/watch?v=xxx"`

### channel
Название канала/автора. Тип: текст. Пример: `"Morag Gamble"`

### language

| Значение | Язык |
|---|---|
| ru | Русский |
| en | Английский |
| es | Испанский |
| ka | Грузинский |

### date_added
Когда источник добавлен. Формат: `YYYY-MM-DD`.

### date_processed
Когда источник обработан. Формат: `YYYY-MM-DD`. Пусто пока не обработан.

## Свойства шаблона "Тема"

### domain
Раздел пермакультуры, к которому относится тема.

| Значение | Раздел |
|---|---|
| фундамент | Этика, принципы, зоны, сектора, паттерны, чтение участка |
| стихии | Почва, вода, климат, ветер, солнце |
| растения | Деревья, лесосад, однолетние, компост, мульча |
| животные | Животные в системе |
| дизайн | Проектирование участка, QGIS |
| субтропики | Субтропическая пермакультура |
| сообщество | Экопоселение, комьюнити |

### priority

| Значение | Когда |
|---|---|
| high | Тема нужна прямо сейчас (привязана к сезону или задаче) |
| medium | Тема важна, но не срочна |
| low | На будущее |

### season
К какому сезону привязана тема.

| Значение | Период |
|---|---|
| весна | Март-Май |
| лето | Июнь-Август |
| осень | Сентябрь-Ноябрь |
| зима | Декабрь-Февраль |
| круглый-год | Не зависит от сезона |

### practice_link
Ссылка на заметку участка где применяется. Тип: текст.
Пример: `"02_Участок/Наблюдения_март_2026"`

## Свойства шаблона "Методичка"

### topic
Ссылка на тему-источник. Тип: текст.
Пример: `"[[Чтение_участка]]"`

### tested
Проверена ли практикой. Тип: чекбокс (true/false).
