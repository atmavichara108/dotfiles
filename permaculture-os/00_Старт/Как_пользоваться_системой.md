# Как пользоваться системой

## Философия

Это не склад информации. Это операционная система для превращения информации в практическое знание и действие.

Правило: если знание не прошло через твою голову и не связано с практикой — оно мусор.


## Три типа заметок

### Источник

Одна заметка = один материал (видео, статья, книга, пост).

Где живёт: `03_Источники/youtube/`, `articles/`, `books/`, `telegram/`
Шаблон: `templates/tpl_источник`
Назначение: сохранить, кратко описать, привязать к теме.
Жизненный цикл: `inbox` → `processed` → `archived`

### Тема

Одна заметка = один предмет изучения. Рабочий верстак.

Где живёт: `01_Обучение/`
Шаблон: `templates/tpl_тема`
Назначение: собрать понимание из нескольких источников, связать с практикой.
Жизненный цикл:

| Статус | Значение |
|---|---|
| 🔴 seed | Тема обозначена, вопросы есть, источников мало |
| 🟠 growing | Изучается, 3+ источников собрано |
| 🟡 harvest | Понимание сложилось, есть план практики |
| 🟢 manual | Переработана в методичку |
| 🔵 tested | Проверена практикой или детально спроектирована |

### Методичка

Одна заметка = итоговая сборка по теме.

Где живёт: `04_Методичка/`
Шаблон: `templates/tpl_методичка`
Назначение: чистовик для повторения, применения и передачи другим.
Жизненный цикл: `draft` → `review` → `done` → `tested` → `shared`


## Три режима работы

### Разведка — 30% времени

Свободный вход: каналы, рекомендации, случайные находки.

Ограничения: 1-2 материала за сессию, каждый получает тег и привязку к теме.

Выход: источник в `03_Источники/` с аннотацией.

### Изучение — 50-60% времени

Целевая работа: одна тема в неделю.

Последовательность: вопрос → источники → выжимка → практика → самопроверка.

Выход: тема в статусе 🟡 harvest.

### Переработка — 10-20% времени

Сборка методички из накопленного. Раз в 1-2 недели, отдельный блок.

Выход: страница методички в статусе `done`.


## Пайплайн знаний

Поток движется в одном направлении, от сырого к готовому:

Источник (видео, статья, пост) → захват через `perm-capture` или вручную → сырая заметка в `03_Источники/` → обработка: смотришь, извлекаешь идеи, тегируешь → привязка к теме в `01_Обучение/` → изучение: собираешь 3+ источников, ищешь суть → тема созревает (seed → growing → harvest) → переработка: пишешь своими словами → методичка в `04_Методичка/` → практика: применяешь на участке → обновление заметок в `02_Участок/`.


## Недельный ритм

| День | Что | Режим | Время |
|---|---|---|---|
| Пн | Тема недели: подбор источников, первый разбор | Изучение | 1.5ч |
| Ср | Тема: углубление, выжимки, связь с практикой | Изучение | 1.5ч |
| Пт | Свободная разведка ИЛИ добор по теме | Разведка | 1-1.5ч |
| Сб | Участок: наблюдения, практика, фото | Практика | 1-2ч |
| Вс | Сборка методички + ревью недели | Переработка | 1.5-2ч |

Сессии вечерние. Утренние добавятся позже.


## Инструменты захвата

### YouTube → Obsidian

Через терминал, одна команда:

`perm-capture "URL"` — захват с англоязычными субтитрами.
`perm-capture_ru "URL"` — захват с русскими субтитрами.
`perm-capture "URL" "почва"` — с привязкой к теме.

Скрипт автоматически скачивает субтитры, создаёт заметку-источник из шаблона, заполняет метаданные. Скрипты лежат в `~/dotfiles/scripts/.local/bin/`.

Субтитры сохраняются в `03_Источники/.media/transcripts/`.
Аудио (если скачивается) в `03_Источники/.media/youtube/`.

### Веб-страница → Obsidian

Расширение Obsidian Web Clipper в браузере → сохраняет в `03_Источники/articles/`.

### Telegram → Obsidian

Пока вручную: копируешь текст → создаёшь заметку из шаблона в `03_Источники/telegram/`.

### AI-ассистент

Транскрипт или тему можно принести в чат. Ассистент помогает: извлечь идеи, перевести, найти источники, проверить методичку, дополнить тему.


## Навигация

### Главный вход

`00_Старт/Главная.canvas` — визуальная карта всей системы.

### MOC-заметки

Каждая папка имеет свой MOC — точку входа:

[[Обучение_MOC]] — все темы и их статусы.
[[Участок_MOC]] — всё про Персиановский участок.
[[Источники_MOC]] — пайплайн обработки материалов.
[[Методичка_MOC]] — готовые знания.
[[Проекты_MOC]] — долгосрочные вектора.

### Реестр каналов

[[Реестр_каналов]] — навигационная карта YouTube-каналов по направлениям, климатам и темам.

### Теги

По предмету: `#почва` `#вода` `#деревья` `#зоны` `#климат` `#лесосад` `#компост`
По типу: `#практика` `#теория`
По привязке: `#мой-участок` `#субтропики` `#solarpunk`

### Горячие клавиши

`Ctrl+O` — быстрое переключение между заметками.
`Ctrl+Shift+F` — полнотекстовый поиск по vault.
`Alt + T` --  вставки шаблона.


## Структура папок

`00_Старт/` — дашборд, навигация, мета-документы.
`01_Обучение/` — темы (рабочие верстаки изучения).
`02_Участок/` — всё про Персиановский участок.
`03_Источники/` — сырые материалы, разложены по типам: `youtube/`, `articles/`, `books/`, `telegram/`. Плюс `.media/` для файлов субтитров и аудио.
`04_Методичка/` — готовые знания (только переработанное).
`05_Проекты/` — Сочи, экопоселение, долгие вектора.
`99_Архив/` — отработанное.
`templates/` — шаблоны заметок.


## Правила гигиены

- Не создавай заметку без шаблона.
* Не оставляй источник без привязки к теме дольше недели.
* Раз в неделю (воскресенье) проверяй inbox-источники.
* Каждая тема должна иметь главный вопрос.
- В методичку — только своими словами.
- После каждой сессии: `git add . && git commit -m "описание" && git push`
