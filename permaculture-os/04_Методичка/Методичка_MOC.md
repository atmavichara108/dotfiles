# Методичка

## Что это
Авторская, сжатая, практическая система понимания каждой темы пермакультуры. Сюда попадает **только переработанное знание** — то, что ты понял, можешь объяснить и применить.

## Правила
1. Не копировать из источников — переформулировать своими словами
2. Каждая страница — максимум 1-2 экрана текста
3. Без мусора, без "может пригодится"
4. Обновлять после практики на участке
5. Это продукт, который можно показать другому человеку
