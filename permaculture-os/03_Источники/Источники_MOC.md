# Источники

## Как работает этот раздел

### Входной поток
Любой материал сначала попадает сюда. Без исключений.

### Типы источников
- `03_Источники/youtube/` — видео с YouTube
- `03_Источники/articles/` — статьи и веб-страницы
- `03_Источники/books/` — конспекты книг и глав
- `03_Источники/telegram/` — заметки из Telegram-каналов

### Статусы источника
- `inbox` — сохранён, не обработан
- `processed` — просмотрен, идеи извлечены, привязан к теме
- `archived` — переработан в тему, можно не возвращаться

### Пайплайн

1. Сохранить сырой материал (шаблон tpl_источник)
2. Извлечь главное (3-5 идей)
3. Привязать к теме из 01_Обучение/
4. Когда тема созрела → переработать в 04_Методичка/
## Навигация
