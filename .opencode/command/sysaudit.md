# Системный аудит dotfiles

Проведи полный аудит системы и сверь с содержимым репо dotfiles.

## 1. Информация о системе

```
uname -a
hostnamectl
df -h /
free -h
```

## 2. Пакеты

```
pacman -Qe | wc -l      # явно установленные
pacman -Qm              # AUR пакеты
pacman -Qq | wc -l      # все установленные
```

## 3. Конфиги в $HOME

```
ls -la ~/.*             # скрытые файлы
ls ~/.config/           # директории конфигов
```

## 4. Сверка с репо dotfiles

Посмотри, какие директории есть в репо:
```
ls /home/rudra/dotfiles/
```

Сравни с тем, что есть в `$HOME` и `~/.config/`. Найди:
- Конфиги в `$HOME`, которых **нет** в репо (кандидаты на добавление)
- Директории в репо, которых **нет** в `$HOME` (незастовлены)

## 5. Dry-run stow

Для каждой директории в репо выполни:
```
cd /home/rudra/dotfiles && stow -n <dir>
```

Отметь, где есть конфликты или дрейф.

## 6. Сервисы

```
systemctl list-units --type=service --state=running | head -20
ss -tlnp | head -20
```

## Формат вывода

Оформи отчёт в формате:

```
# Системный аудит — YYYY-MM-DD

## Система
- OS: ...
- Kernel: ...
- Disk: ...
- RAM: ...

## Пакеты
- Всего: N
- Явно установленные: N
- AUR: N (список)

## Конфиги вне репо
- ~/.config/XYZ — есть в системе, нет в репо
- ...

## Дрейф конфигов
- dir/ — конфликт при stow (описание)
- ...

## Слушающие сервисы
- port N: service
- ...

## Рекомендации
1. `команда` — пояснение
2. `команда` — пояснение
```
