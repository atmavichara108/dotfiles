# Команда: Запиши на потом

> Добавляет запись в реестр отложенных задач `docs/deferred.md`.
> Использовать когда Макс говорит «запиши на потом», «отложи», «someday», «maybe».

## Процесс

### 1. Извлеки суть

Определи:
- **Краткое название** (одна строка)
- **Суть** (что хотели сделать, 1-2 предложения)
- **Почему отложено** (причина)
- **Триггер возврата** (что должно произойти, чтобы вернуться)
- **Связано** (ссылки на ADR, docs, другие записи)

### 2. Добавь запись в `docs/deferred.md`

Формат:

```markdown
### YYYY-MM-DD: Краткое название
**Источник:** контекст (чей запрос, какой аудит, какая сессия)
**Суть:** что хотели сделать
**Почему отложено:** причина
**Триггер возврата:** что должно произойти, чтобы вернуться
**Связано:** ссылки на ADR, docs, issues
```

### 3. Обнови статистику в конце файла

Увеличь `Всего записей: N` на 1.

### 4. Сообщи Максу

«Записал: «Название» → docs/deferred.md. Всего отложенных задач: N.»

## Примеры

```
### 2026-06-30: Интеграция calcurse с Taskwarrior
**Источник:** Обсуждение roadmpa 2026-06-30
**Суть:** Настроить синхронизацию календаря с задачами
**Почему отложено:** Нет текущей потребности
**Триггер возврата:** При настройке Taskwarrior-экосистемы
**Связано:** Taskwarrior (реестр отложенных)
```
