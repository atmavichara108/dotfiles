# /fix — автоматическое исправление пакета

Цель: исправить ошибки в пакете `$ARGUMENTS`

## Цикл (до 3 итераций)

### Шаг 1. Верификация

Запустить verifier:

```
task(agent="verifier", prompt="Проверить пакет $ARGUMENTS")
```

### Шаг 2. Развилка

- **FAIL:**
  1. Прочитать отчёт verifier (какие проверки ❌)
  2. Исправить ошибки в коде:
     - Синтаксические ошибки Python
     - Проблемы с stow (конфликты, отсутствующие файлы)
     - Проблемы с systemd сервисами (неверные пути, зависимости)
  3. Перейти к шагу 1 (следующая итерация)

- **PASS:** перейти к шагу 3

### Шаг 3. Финал

Вернуть финальный отчёт.

## Формат ответа

```
## Отчёт исправления: <пакет>

**Итерации:** <N>

**Исправлено:**
- <ошибка 1> — исправлено
- <ошибка 2> — исправлено

**Финальный статус verifier:** ✅ PASS / ❌ FAIL
```

## Лимиты

**HARD STOP после 3 verify-циклов.** Если на 3-й итерации всё ещё FAIL — отпиши оставшиеся блокеры и STOP.

## Правила

- Каждую итерацию вызывать verifier заново — он проверяет актуальное состояние.
- Исправлять только те ошибки, которые указал verifier.
- Если verifier недоступен/ошибка — STOP с пометкой.
