# /spell — исправитель текста владельца

Владелец пишет с ошибками и просит чистый вариант «как автозамена на
смартфоне» (слово 2026-10-24). Живая замена в поле ввода TUI невозможна
(hook'а перезаписи ввода в API OpenCode нет), поэтому команда даёт тот же
результат одним шагом: владелец вставляет текст — получает исправленный.

## Правила (S0-А5: владельцу — человеческий язык)

1. Выдать **только исправленный текст** в блоке «✅ Чистый вариант:».
2. Исправлять: опечатки, грамматику, пунктуацию, регистр, склейки слов.
3. **Не менять**: смысл, терминологию, стиль, порядок мыслей, латиницу/кириллицу
   в именах собственных. Сомнительное слово — оставить как есть.
4. Никаких комментариев, если владелец не просил разбор; разбор ошибок —
   только по просьбе («разбери»).
5. Если текст пустой или нечего исправлять — сказать «чисто, правок нет».
6. Смысл превыше буквы: если правка меняет смысл — не делать.
