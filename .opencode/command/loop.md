# /loop — closed-loop реализация

Цель: $ARGUMENTS

## Цикл

1. **Build.** Реализуй следующий инкремент к цели. Прочитай контекст (AGENTS.md, спек, релевантные конфиги), внеси изменение, покажи diff.

2. **Verify.** Вызови verifier:
   ```
   task(agent="verifier", prompt="verify: применимость изменения — $ARGUMENTS. Проверь синтаксис (bash -n / py_compile), stow -n для затронутых пакетов, разрешение зависимостей, идемпотентность.")
   ```

3. **Развилка:**
   - **FAIL:** примени ТОЛЬКО фикс listar указанными verifier блокерами, вернись к шагу 1.
   - **PASS:** переходит к шагу 4.

4. **Финал.** Резюмируй: что сделано, сколько циклов, финальный вердикт. STOP.

## Лимиты

**HARD STOP после 5 verify-циклов.** Если на 5-й итерации всё ещё FAIL — отпиши блокеры, что не получилось, и STOP. Не зацикливайся.

## Правила

- Verifier — единственный источник PASS/FAIL. Не принимай собственные решения о готовности.
- На каждом цикле вызывай verifier заново — он смотрит актуальный diff.
- Если verifier недоступен/ошибка — STOP с пометкой, не пытайся верифицировать сам.
- Коммит — отдельной командой (`/commit`), не внутри loop.
