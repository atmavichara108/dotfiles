# /test — автоматическая верификация пакета

Цель: проверить пакет `$ARGUMENTS`

## Пайплайн

### 1. Синтаксис Python (если есть .py файлы)

```bash
python3 -m py_compile ~/.local/bin/<имя-скрипта>
```

Если Python-файлов нет — пропустить.

### 2. Stow dry-run

```bash
cd ~/dotfiles && stow -n <пакет>
```

Проверяет, что пакет корректно разворачивается через GNU Stow.

### 3. Статус systemd services (если есть .service файлы)

```bash
systemctl --user status <service-name>
```

Проверяет активен ли юнит, нет ли ошибок в статусе.

### 4. Логи (последние 50 строк)

```bash
journalctl --user -u <service-name> -n 50
```

Проверяет наличие ошибок в логах.

### 5. Проверка файлов

```bash
ls -la ~/.local/bin/<имя-скрипта>
ls -la ~/.config/systemd/user/<service-name>
```

Убедиться, что файлы на месте, права корректны.

## Развилка

- **PASS:** вернуть отчёт со всеми ✅
- **FAIL:** вернуть отчёт с ❌ и деталями ошибок

## Формат ответа

```
## Отчёт проверки: <пакет>

| Проверка | Статус |
|----------|--------|
| Синтаксис Python | ✅/❌ |
| Stow dry-run | ✅/❌ |
| systemd service | ✅/❌ |
| Логи | ✅/❌ |

**Детали:**
- ...
```

## Лимиты

- Не редактировать файлы — только проверка.
- Если какая-то проверка неприменима (нет Python/serivce) — отметить как N/A.
