# /stow — массовые файловые операции dotfiles

Цель: $ARGUMENTS

## Пайплайн

1. **Планирование.** Builder анализирует задачу, составляет список операций (mkdir, cp, stow, ln). Определяет затронутые пакеты и целевые пути.

2. **Делегирование.** Builder вызывает stow-ops:
   ```
   task(agent="stow-ops", prompt="Выполни операции: <список>. Пакеты: <список>. Целевые пути: <список>.")
   ```

3. **Верификация.** После выполнения stow-ops, builder вызывает verifier:
   ```
   task(agent="verifier", prompt="verify: применимость stow-операций — $ARGUMENTS. Проверь stow -n для затронутых пакетов, симлинки созданы, нет конфликтов.")
   ```

4. **Развилка:**
   - **FAIL:** builder анализирует блокеры, вызывает stow-ops для фикса, вернись к шагу 2.
   - **PASS:** переходит к шагу 5.

5. **Финал.** Builder резюмирует: что сделано, сколько пакетов создано/обновлено, финальный вердикт. STOP.

## Лимиты

**HARD STOP после 3 verify-циклов.** Если на 3-й итерации всё ещё FAIL — отпиши блокеры и STOP.

## Примеры использования

```
/stow создать пакет flameshot из ~/.config/flameshot
/stow исправить дрейф gtk-4.0 — добавить в пакет gtk
/stow объединить taskwarrior-tui, taskvanguard, timewarrior в пакет task-tools
/stow массовый restow всех пакетов после реструктуризации
```

## Правила

- Builder планирует, stow-ops выполняет, verifier проверяет.
- Не редактируй содержимое конфигов — только файловые операции.
- Бэкапы обязательны перед заменой реальных файлов.
- Коммит — отдельной командой, не внутри /stow.
