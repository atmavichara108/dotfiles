# /inbox — приёмная: очередь, проверка, данные классификатора

Покажи состояние очереди идей и данных под классификатор. Только чтение.

Контекст: $ARGUMENTS
(необязательный фильтр — ID позиции или номер волны; без аргумента — вся очередь)

Формат ответа — три секции: **Идеи / Проверка / Данные классификатора**.
Коротко, на русском. Никаких секретов, сырых команд и полного содержимого файлов:
только ID, темы, статусы и счётчики.

## 1. Идеи — выгрузка очереди

Прочитай `.opencode/memory/inbox.md`.

- Покажи **активные/открытые** позиции коротким списком:
  `И-NN — тема (одна строка, сути) — статус`.
- Закрытые (статус `✔` / «выполнено» / «закрыто») не перечисляй — одной строкой:
  «закрыто: N».
- Файл целиком не копируй, длинные описания не цитируй.

## 2. Проверка записи (правило приёма идей, И-03)

Для каждой позиции очереди проверь обязательные поля: **ID, тема, владелец,
статус** (набор колонок в таблицах волн может отличаться, но эти четыре поля
обязательны в каждой строке).

- Полная позиция → учтена в счёте «OK: N».
- Битая/неполная → отдельной строкой: `И-NN — нет поля: …`.
- Проверка только читает: сам файл не правишь, исправления — отдельным
  согласованным шагом.

## 3. Данные классификатора (И-22)

Если есть `~/.local/state/opencode/command-observations.jsonl` — посчитай
агрегат по метаданным записей (поля `operation`, `module`, `module_candidate`,
`subagent_candidate`, `session_count`):

- всего записей;
- top повторяющихся операций (`operation` × count, топ-5…10);
- сколько записей с `module_candidate=true` и `subagent_candidate=true`;
- при желании — `module` × count.

Только счётчики и метки — **НЕ сырое содержимое команд**. Если файла нет —
так и скажи: «данных классификатора нет».

## Формат ответа

```
### Идеи
- И-NN — тема … — статус …
- закрыто: N

### Проверка
- OK: N позиций; неполные: И-NN (нет владельца), …

### Данные классификатора
- Записей: N; module_candidate: N; subagent_candidate: N
- Top операции: op ×N, …
- или «данных классификатора нет»
```

## Правила

- Только чтение и агрегаты: никаких правок файлов, коммитов, секретов.
- Если аргумент-фильтр задан — сужай все три секции до него.
