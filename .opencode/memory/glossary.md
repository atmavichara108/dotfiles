# Лексикон Корабля

Один термин — одно значение. Слова, которые пользователь ввёл или утвердил,
помечены как цитата (`basis: quoted`); остальное — наши рабочие обозначения и
подлежат правке по его слову.

## Про саму систему

| Термин | Значение | Происхождение |
|---|---|---|
| **Корабль** | вся наша Вайб-экосистема целиком: ноутбук, ОС, проекты, движок, все конфиги и агенты | цитата: «назовём всю нашу Вайб экосистему Кораблём» |
| **Обвязка** | то, что связывает движок и работу: конфиги, плагины, агенты, скрипты | канон пользователя (сам использует слово) |
| **Такелаж** | синоним обвязки, который передаёт тягу двигателя в ход корабля | предложено как замена «харнессу» |
| ~~харнесс~~ | **снято с канона.** Не использовать | цитата: «мне это слово не нравиться, его аллегория неэтична и в целом неверна», «ллм не подобна тягловой лошади находящейся ниже человека в пищевой цепочке» |

## Про топливо и двигатель

| Термин | Значение | Происхождение |
|---|---|---|
| **Топливо** | сама ЛЛМ — источник энергии | цитата: «ллм - топливо» |
| **Двигатель** | сдк-портируемая обвязка, приводящая топливо в работу; сейчас это opencode | цитата: «двигатель - сдк-портируемый, например опенкод это двигатель в данный момент» |
| **Дополнительный движок / мкод** | подключаемый второй движок; заточен на разработку кода и интеграцию в систему, кроме системных глобальных конфигов opencode/mcode | цитата: «к нему может подключаться мкод как дополнительный движок» |
| **Правило правки движка** | изнутри, в дозволенных границах, можно модифицировать сам opencode; для разработчиков мкода — собирать баги и предлагать решения | цитата |

## Про организацию работы

| Термин | Значение | Происхождение |
|---|---|---|
| **Отсек** | контейнер работы: тема, владелец, зона, состояние | цитата: «отсек — контейнер подходит» |
| **Верстак** | один активный поток внутри отсека | рабочее обозначение |
| **Лаба** | **зарезервировано**: пригодится под верхнеуровневую структуризацию (структурный анализ, структурализм) | цитата: «лаба тоже норм, но думаю ещё пригодиться это слово» |
| **Инбокс / отсек-0 / Приёмная** | место приёма: идея или тулс получает ID и встаёт в очередь; приёмная, а не склад | цитата: «в отдельный отсек (получается сначала в нулевой отсек инбокс) на очередь» |
| **Формовочная** | отсек, где собираются субагенты | рабочее обозначение по смыслу его системы |
| **Контрагент** | тот, кто создаёт субагентов; работает через архетипы, а не свободным сочинительством | цитата: «первого контрагента который будет уметь делать только одно - создавать субагета» |
| **Архетип / слот** | форма сборки агента: жёсткий скелет (права из белого списка, поля, модель), который заполняется значениями | рабочее обозначение (противопоставлено «сочинительству») |
| **Классификатор команд** | собирает и классифицирует команды сессии: >3 повторов — претендент на модуль; 5+ команд-модулей — субагент; модули эволюционируют | цитата (дословно в инбоксе и handoff) |
| **Око / индекс** | мгновенный доступ к состоянию вместо чтения реестров целиком | цитата: «мгновенный доступ оком в любую точку требует индекса» |
| **Журнал** | append-only запись того, что обязано выжить (черновики, состояние, решения) | рабочее обозначение волны 1 |
| **Горячая память** | связка «журнал + индекс + CLI», где RAM — только кеш | принято пользователем (И-10…И-14) |
| **Сухой док** | дисциплина отката: мелкие коммиты, ветка на сюжет, возможность вернуть состояние | рабочее обозначение (по смыслу его слов) |
| **Учебная тревога (drill)** | плановая проверка аварийного инструмента, чтобы он не оказался ржавым в нужный момент | рабочее обозначение (И-32) |

## Нормы, которые держим

1. **Дословность.** Сообщения пользователя читаются целиком и записываются
   дословно, без саммари; в память попадают без искажений, `basis: quoted`.
   Правило действует повсеместно (И-04).
2. **Одна клавиша не должна необратимо рождать потерю.** Разрушительные
   действия требуют подтверждения (инцидент 2026-10-12).
3. **Важное состояние обязано иметь копию на диске.** RAM — кеш, не хранилище.
4. **Никаких секретов** в репозитории и в журналах.
