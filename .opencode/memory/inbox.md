# Отсек-0 «Приёмная» — очередь

Правило отсека: **любая идея или тулс сначала сюда**, получает ID, и только потом
назначается в отсек. Отсек-0 — приёмная, а не склад (basis: quoted — «в нулевой
инбокс» как очередь, слова пользователя 2026-10-12).

Принцип порядка: сначала то, что **снимает неоднозначность и делает состояние
выживаемым**, затем ядро (память), затем агентский слой, затем надстройки, затем
крупные направления. Причина — каждый следующий слой опирается на предыдущий:
реестр даёт ключи для памяти, память даёт место для жизни агентов, жизнь агентов
даёт материал для классификатора.

Ограничение (канон): один worktree — одна активная ветка. Одновременно не более
**3 активных позиций**, 5 — только если позиции не пересекаются по файлам.

## Лексикон (черновик, basis: quoted где слова пользователя)

- **Корабль / обвязка** — вся наша Вайб-экосистема (слово «харнесс» из канона
  снято: неверная и неэтичная коннотация).
- **Отсек** — контейнер (принято пользователем: «отсек — контейнер подходит»);
  **верстак** — один активный поток внутри отсека.
- **Лаба** — приберегается под верхнеуровневую структуризацию (структурный
  анализ, структурализм).
- **Инбокс / отсек-0** — приёмная: идея получает ID и встаёт в очередь.
- **Контрагент** — то, что создаёт субагентов (первая его функция) и работает
  через архитепы, а не свободным сочинительством.
- **Око / индекс** — мгновенный доступ к состоянию (см. волну 1).
- **Сухой док** — дисциплина отката (мелкие коммиты, ветка на сюжет).
- **Двигатель/топливо/мкод** — ЛЛМ есть топливо; двигатель сдк-портируемый
  (opencode сейчас), мкод — подключаемый дополнительный движок.
