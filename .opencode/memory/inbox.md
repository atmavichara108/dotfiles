# Отсек-0 «Приёмная» — очередь

Правила параллельной работы primary с субагентами — `.opencode/memory/orchestration.md`.

Правило отсека: **любая идея или тулс сначала сюда**, получает ID, и только потом
назначается в отсек. Отсек-0 — приёмная, а не склад.

Очередь принята пользователем 2026-10-13 **с поправками** (внесены ниже).
Принцип порядка: сначала то, что снимает неоднозначность и делает состояние
выживаемым; затем ядро (память); затем агентский слой; затем надстройки и лабы.
Ограничение (канон): один worktree — одна активная ветка; не более 3 активных
позиций, 5 — только при непересекающихся файловых зонах.

эволюции** (что собирать и когда). Конвейер: команды сессии → модули → заказ →
сборка из архетипа → проверка → реестр жизненного цикла.

## Лексикон (черновик)

- **Корабль / обвязка** — вся наша Вайб-экосистема; слово «харнесс» снято с канона.
- **Отсек** — контейнер; **верстак** — один активный поток внутри отсека.
- **Лаба** — приберегается под верхнеуровневую структуризацию.
- **Инбокс / отсек-0** — приёмная: идея получает ID и встаёт в очередь.
- **Формовочная** — цех, где собираются субагенты.
- **Контрагент** — тот, кто создаёт субагентов; работает через архетипы.
- **Око / индекс** — мгновенный доступ к состоянию.
- **Сухой док** — дисциплина отката.
- **Топливо / двигатель / мкод** — ЛЛМ есть топливо; двигатель сдк-портируемый
  (opencode сейчас); мкод — подключаемый дополнительный движок и лаба кода.
