## Лексикон (черновик)

- **Корабль / обвязка** — вся наша Вайб-экосистема; слово «харнесс» снято с канона.
- **Отсек** — контейнер; **верстак** — один активный поток внутри отсека.
- **Лаба** — приберегается под верхнеуровневую структуризацию.
- **Инбокс / отсек-0** — приёмная: идея получает ID и встаёт в очередь.
- **Формовочная** — цех, где собираются субагенты.
- **Контрагент** — тот, кто создаёт субагентов; работает через архетипы.
- **Око / индекс** — мгновенный доступ к состоянию.
- **Сухой док** — дисциплина отката.
- **Топливо / двигатель / мкод** — ЛЛМ есть топливо; двигатель сдк-портируемый
  (opencode сейчас); мкод — подключаемый дополнительный движок и лаба кода.
