# Реестр отсеков

Назначение: одно место, где видно **что сейчас открыто, кем владеется и где
лежит**. Реестр — это то, по чему будет ходить «око» (индекс горячей памяти,
И-11): без записи в реестр отсек для глаза не существует.

Правила ведения:

1. Новый отсек = новая строка здесь + коммит. **Без записи в реестр отсек не
   открывается.**
2. Один отсек = одна тема = одна файловая зона. Пересечение зон двух активных
   отсеков запрещено (иначе конфликты коммитов).
3. Одновременно активно не более **3** отсеков; 5 — только если зоны не
   пересекаются (канон: один worktree, одна активная ветка).
4. Смена состояния = правка строки с датой. История — в git, отдельные логи не
   заводим.
5. Отсеки называются по ИМЕНИ; числа — производные и уточняются (см. открытый
   вопрос ниже).

## Открытый вопрос: нумерация

Пользователь называл отсеки порядком работы: «в первой мы занимаемся созданием
контрагента… во второй внедрение голосового управления… а в нулевой инбокс»
(basis: quoted, первое сообщение 2026-10-12). Позже сказал, что мкод может быть
«второй лабой со своими контейнерами» (2026-10-13) — это конфликтует с номером
голоса.

Поэтому: отсеки адресуются **именем**, номера помечены «?» и будут закреплены
отдельным решением. Пока фиксируем как есть, без самовольной перенумерации.
