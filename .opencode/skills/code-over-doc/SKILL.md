# Code Over Doc — канон против факта (Р-121)

Правило закреплено **программно** (не «совестью агентов»): факт/код на диске — первичный
источник истины; документация вторична.

| Слой | Что принуждает |
|------|----------------|
| канон Р-121 (AGENTS.md) | при противоречии документации и кода — следовать коду |
| требование отчёта | в финальном ответе указать **каждое** найденное несоответствие документации и кода |
| evidence на диск | зафиксировать расхождение (persist.py / рукописно) до действий |

## Правила

1. **Код/факт важнее документации.** Если документация (AGENTS.md, канон, спека,
   реестр, инструкция) противоречит существующему коду или факту на диске — следуй
   соглашениям, принятым в коде.
2. **Укажи каждое несоответствие.** В финальном ответе перечисли ВСЕ найденные
   противоречия документация↔код/факт, а не только то, что чинил.
3. **Не переписывай молча.** Не молчи о расхождении: зафиксируй факт (evidence на
   диск / рапорт) и иди по коду. Молча следовать устаревшей документации — дефект.
4. **Проверяй по коду, не по описанию.** Реальный механизм (что делает скрипт/плагин/
   команда) узнаётся из кода/факта, не из его описания в документации.
5. **Обходы для блокировок** — если документация мешает рабочему действию (напр.
   INC-18 из-за устаревшего реестра), используй канонический источник факта и
   зафиксируй дефект для владельца зоны.

## Поток

1. Встретил противоречие документация ↔ код/факт.
2. Сверься с кодом/фактом на диске (grep/чтение файла/реальный прогон).
3. Следуй коду. Зафиксируй расхождение (persist.py evidence / запись).
4. В финальном ответе — перечисли **каждое** несоответствие.

## Когда использовать

- Документация описывает одно, код делает другое.
- Реестр/манифест не отражает фактическое состояние сессии/артефакта.
- Описание инструмента устарело относительно его реального поведения.

## Когда НЕ использовать

- Нет противоречия (документация и код согласованы) — обычный порядок.

## Запреты

- Следовать устаревшей документации, зная, что код делает иначе.
- Умолчать о найденном расхождении (не указать в ответе).
- Править чужую зону (код/реестр) без передачи владельцу, обходя канон.
